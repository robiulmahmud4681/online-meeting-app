Automatic Gmail Notifications to All Members

Connect a free Google Apps Script Web App URL (takes 2 minutes, sends directly from your Gmail to every approved member's Gmail whenever a notice is posted or a live meeting starts).

How to Set Up Free Gmail Sending (Google Apps Script):

  1. Open script.google.com while signed into your official Gmail account and click New project.
  2. Delete the default code, click Copy Apps Script Code above, and paste it in.
  3. Click Deploy → New deployment → Web app, set Execute as: Me and Who has access: Anyone, then authorize Gmail permission.
  4. Copy the generated Web App URL (ends with /exec), paste it above, and click Save Gmail Settings.
